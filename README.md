## ✨ About

A lightweight, dependency-free personal website built with plain HTML (and inline CSS/JS). It is automatically deployed to **GitHub Pages** via a GitHub Actions workflow on every push.

## 🛠️ Tech Stack

`HTML` · `CSS` · `JavaScript` · `GitHub Actions` · `GitHub Pages`

## 📁 Project Structure

```
portfolio/
├── index.html              # The complete single-page site
└── .github/workflows/      # GitHub Pages deployment workflow
```

## 🚀 Run Locally

```bash
git clone https://github.com/nihatgaribli/portfolio.git
cd portfolio

# Just open the file in your browser:
start index.html      # Windows
# open index.html     # macOS
```

## 🌍 Deployment

Pushes to the default branch trigger the GitHub Actions workflow, which publishes the site to GitHub Pages. Make sure **Settings → Pages** is set to deploy from GitHub Actions.
